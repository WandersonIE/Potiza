# Potiza

Aplicativo móvel Android criado com Expo + React Native para centralizar criação de imagens, vídeos, áudios, documentos, chat de IA e biblioteca pessoal.

## Requisitos

- Node.js 18+
- Expo CLI
- Android Studio + emulador ou dispositivo físico Android

## Instalação

```bash
npm install
npm run android
```

Se estiver usando um emulador ou dispositivo conectado, o app será iniciado em modo Android.

## Estrutura atual

- Tela inicial com visão geral do app
- Chat de IA com mensagens mockadas
- Biblioteca de arquivos
- Fluxos de criação de mídia e documentos
- Base visual para futuras integrações com IA, geração de conteúdo e leitura de arquivos do celular
